# 메홍키덜트샾

RC, 프라모델, 피규어를 판매하는 온라인 쇼핑몰입니다.

## 소개

- **판매 상품**: RC(자동차/드론/보트), 프라모델(건담/전투기/전함/로봇), 피규어(히어로/동물/우주인)
- **주요 고객**: 자녀를 키우는 30~50대
- **컨셉 컬러**: 따뜻한 주황색 + 시원한 파란색
- **분위기**: 인사이팅하고 스포티한 느낌

## 페이지 구성

| 파일 | 설명 |
|------|------|
| [index.html](index.html) | 홈 화면 (배너, 카테고리 소개, 공지사항/인기상품) |
| [rc.html](rc.html) | RC 카테고리 상품 목록 |
| [plamo.html](plamo.html) | 프라모델 카테고리 상품 목록 |
| [figure.html](figure.html) | 피규어 카테고리 상품 목록 |

## 주요 기능

- 헤더 검색창으로 상품명 검색 시 해당 상품 페이지로 이동
- 왼쪽 사이드바 카테고리 메뉴로 세부 상품 바로가기
- 홈 화면 자동 슬라이드 배너
- 상품 이미지에 마우스를 올리면 확대되는 효과
- 1주년 기념 전상품 20% 할인 표시
- 담기 버튼 클릭 시 알림창 표시

## 기술 스택

HTML, CSS, JavaScript로만 제작된 정적 웹페이지입니다. (별도 프레임워크나 서버 없이 브라우저에서 바로 열어볼 수 있습니다.)
